# 권리 및 배포 고지

이 패치는 Heroes of Might and Magic II Gold DOS판의 비공식 한국어화 프로젝트입니다.

- 원작 게임, 그래픽, 문자열 원문, 지도, 캠페인, 음악, 영상, 상표의 권리는 각 권리자에게 있습니다.
- 이 프로젝트는 원작 권리자, Ubisoft, New World Computing, 3DO 또는 GOG의 공식 프로젝트가 아닙니다.
- 배포 ZIP에는 완성된 게임 EXE·AGG·H2C·HXC 파일이 들어 있지 않습니다.
- 사용자는 적법하게 보유한 지원 GOG 영문 설치본을 직접 준비해야 합니다.
- 바이너리 델타는 정확한 지원 원본 해시가 확인된 경우에만 적용됩니다.
- beta.6에서 한글 글리프를 만드는 `NanumGothicCoding-Regular.ttf`만 글꼴 파일로 동봉합니다. 이 파일은 SIL Open Font License 1.1을 따릅니다.
- 사용자 글꼴 선택 스크립트나 명령줄 옵션은 제공하지 않습니다.
- 바탕체 파일과 바탕체에서 미리 만든 고정 래스터는 저장소와 배포 ZIP에 포함하지 않습니다.
- beta.3까지 시험적으로 수정한 이미지 UI 4개도 배포물에서 제거하며, 해당 화면은 원본 영어 이미지를 사용합니다.
- 모집 창의 `Cost per troop:`은 설치 시 나눔고딕코딩 작은 글리프로 `병력당 비용:`을 생성하는 한정된 예외이며, 완성 래스터는 배포하지 않습니다.

프로젝트에서 작성한 소스와 번역 데이터는 `GPL-2.0-only`로 배포됩니다. 라이선스 전문은 `COPYING.GPL-2.0`에 있습니다.

외부 번역 참고 자료, 나눔고딕코딩, 폰트 처리 라이브러리와 그 라이선스는 `THIRD_PARTY_NOTICES.md`에 기록했습니다.
