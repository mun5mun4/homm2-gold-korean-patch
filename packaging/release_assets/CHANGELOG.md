# 변경 기록

## v0.9.0-beta.9 — 2026-08-27

- OFL 1.1의 `Iropke Batang Medium`을 동봉하고 기본 설치 글꼴로 변경
- 기본 설치에서 874자 게임 글리프, 한글 버튼과 `병력당 비용:`을 이롭게 바탕체로 동적 생성
- 빠진 매핑 문자는 동봉한 나눔고딕코딩으로 보완
- 사용자 글꼴 선택 기능과 설치 시 동적 생성 방식을 그대로 유지
- 이롭게 바탕체와 나눔고딕코딩의 OFL 1.1 및 Reserved Font Name 고지를 함께 배포
- 공개 beta.4·beta.5·beta.6·beta.7·beta.8 설치본에서 beta.9 직접 업그레이드 지원

## v0.9.0-beta.8 — 2026-08-27

- 셀 바닥 정렬 대신 FreeType bearing을 보존하는 typographic 기준선 렌더러 v3 적용
- 선택·보완 글꼴의 공통 ink union으로 한 줄의 픽셀 크기와 기준선을 통일하고 글꼴별 수직 위치 어긋남 수정
- `INSTALL_CUSTOM_FONT.cmd`와 사용자 글꼴 명령줄 선택 경로 복구
- 사용자 소유 TTF·OTF·TTC·OTC는 설치 시 로컬에서만 읽고 배포물에 복사하지 않으며, 누락 문자는 동봉한 나눔고딕코딩으로 보완
- 게임 글리프와 한글 버튼·`병력당 비용:` 문구를 같은 선택 글꼴에서 생성
- 메인 메뉴와 한글화 대상으로 선언하지 않은 이미지 UI는 원본 모습으로 보존
- 이롭게 바탕체는 사용자가 로컬에서 선택한 렌더러 수동 검증 예시로만 사용했으며, 글꼴 파일·생성 래스터·시험용 AGG는 저장소와 배포 ZIP에서 제외
- 배포 ZIP에는 나눔고딕코딩 이외의 글꼴 파일이 들어가지 않도록 allowlist 유지
- 공개 beta.4·beta.5·beta.6·beta.7 설치본에서 beta.8 직접 업그레이드 지원
- 공개 beta.7 manifest를 기존 beta.4·beta.5·beta.6 manifest와 함께 고정 검증

beta.1~beta.3 사용자는 해당 버전을 제거해 원본을 복구한 뒤 beta.8을 설치해야 합니다.

- 공개 beta.4·beta.5·beta.6 설치본에서 beta.7 `INSTALL.cmd` 직접 업그레이드 지원
- 공개 beta.6 manifest를 beta.4·beta.5 manifest와 함께 고정 검증

beta.1~beta.3 사용자는 해당 버전을 제거해 원본을 복구한 뒤 beta.7를 설치해야 합니다.

- 사용자 글꼴 선택 스크립트와 명령줄 옵션 제거

## v0.9.0-beta.5 — 2026-08-24

- 기본 글꼴을 OFL 1.1의 `NanumGothicCoding Regular`로 변경
- 일반 13x14·작은 11x12 논리 셀과 face 공통 기준선을 쓰는 렌더러 v2로 바꿔 beta.4 글자 높이 회귀 수정

- `HEROWIND.BIN`의 `Knowledge` 10바이트 슬롯을 `지력`으로 교정하고 폰트 없는 `HEROES2.AGG` 기반에 번역 BIN 8개 유지
- beta.4 기본 설치본은 `INSTALL.cmd`, 사용자 글꼴 설치본은 글꼴을 다시 고른 `INSTALL_CUSTOM_FONT.cmd`로 직접 업그레이드 지원
- 고정 beta.4 manifest와 receipt를 검증하고 실패 시 beta.4로 롤백하며, beta.5 제거 시 최초 GOG 원본 복원

beta.1~beta.3 사용자는 해당 버전을 제거해 원본을 복구한 뒤 beta.5를 설치해야 합니다.

## v0.9.0-beta.4 — 2026-08-24

- 배포 가능한 나눔명조 Regular(OFL 1.1)를 기본 글꼴로 변경
- `INSTALL.cmd`가 설치 시 필요한 874자 한글 글리프를 생성하도록 변경
- `INSTALL_CUSTOM_FONT.cmd`, `--choose-font`, `--font-file`, `--font-index`를 추가해 로컬 TTF·OTF·TTC·OTC를 직접 선택할 수 있도록 함
- 선택 글꼴에 없는 글자는 동봉한 나눔명조로 자동 보완
- 사용자 선택 글꼴 파일을 복사·수집·업로드·배포하지 않고 사용자 PC에서만 글리프를 생성하도록 함
- 글꼴별 AGG 실제 해시를 설치 receipt에 기록해 검증과 안전한 제거에 사용
- 바탕체 파일과 바탕체에서 만든 고정 래스터를 배포물에서 제거
- 시험적으로 수정했던 이미지 UI 4개를 배포 범위에서 빼고 원본 영어 이미지로 복원
- 런타임 글리프 생성을 위해 Pillow 12.0.0과 해당 라이선스 고지를 추가

기존 beta.1~beta.3 사용자는 이전 버전을 제거해 원본을 복구한 뒤 beta.4를 설치해야 합니다. 설치 후 글꼴을 바꿀 때도 제거 후 재설치가 필요합니다.

## v0.9.0-beta.3 — 2026-08-23

- H2K3 외부 문자열 은행을 게임 본체 진입 전에 초기화
- Object2 기반 문장 descriptor 155개와 로더 허용 범위를 실기 재배치 주소 `+0x204000`으로 교정

- 중립 부대 합류 제목·문장을 한국어로 교정하고 외부 은행과 EXE 예비 문구에 함께 수록

## v0.9.0-beta.2 — 2026-08-23

`v0.9.0-beta.1`을 대체하는 정리 배포판입니다. 게임 패치 내용은 같으며 GOG Galaxy 기본 설치 경로 자동 탐지와 공개 패키징을 정리했습니다.

## v0.9.0-beta.1 — 2026-08-23

저장소 패키징 범위 문제로 철회되었습니다. 한국어 패치 내용은 beta.2에 그대로 포함됩니다.

- 오리지널·확장 캠페인 맵 47개 번역 적용
- 주요 비이미지 인터페이스, 전투 로그, 주문·유물·모험 시설 문구 적용
- H2K3 외부 문자열 은행과 874행 글리프 매핑 기반 활성판 배포
- 마지막 적 처치 뒤 캠페인 전환 정지 원인 수정
- 전투 피해·부분 손실 로그를 `공격: 피해 N`, `손실: N`으로 정리
- 대상 주문 로그를 `영웅: 대상에게 주문 시전.` 어순으로 수정
- `air elementals` 직접 EXE 폴백을 `공기정령`으로 수정
- GOG 원본 50개를 검증하는 트랜잭션 델타 설치·검증·제거 도구 추가

알려진 제한:

- 그림에 포함된 영문 버튼과 제목은 아직 번역하지 않음
- 일반 MP2/MX2 지도는 번역 범위에서 제외
- `2000 금`처럼 공용 자원 조합 형식은 파급 분석 전까지 유지
