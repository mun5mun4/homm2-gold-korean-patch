# beta.13 메인 메뉴 그래픽

사용자가 게임에서 확인한 메뉴 5종을 beta.12에 추가합니다. `새 게임`, `불러오기`, `최고 기록`, `제작진`, `종료`와 각 4개 상태, 기본판·확장판 배경에 포함된 버튼을 함께 반영합니다. 일반 버튼·글리프·번역·영상 자막은 beta.12와 같습니다.

## 표현과 수정 범위

글자는 특정 동봉 글꼴을 바꾼 결과가 아니라 AI 생성 시안에서 추출한 전용 형태입니다. native 크기와 팔레트에 맞춰 위치·금갈색 명암·부드러운 1픽셀 가장자리를 보정했습니다. 나무판 바탕을 보완하고 방패의 징과 테두리를 유지했습니다. 메뉴는 기본·사용자 글꼴 설치에 동일하게 적용합니다.

불러오기에서 x=29·50은 어두운 판자 골이고 x=30·51은 바로 오른쪽 나무 모서리입니다. 모서리까지 원본으로 덮어쓰던 처리를 고쳐 그 위의 한글 획을 살렸습니다. 좌표는 0부터 시작하는 버튼 내부 좌표입니다.

가장자리 색을 전체 팔레트에서 고르는 과정에서 221번이 4픽셀에 섞인 오류도 수정했습니다. 기본 상태 `(30,27)`, `(30,41)`, `(51,55)`와 배경 상태 `(30,34)`를 거의 같은 고정색 210번으로 바꿨습니다. 나머지 픽셀은 승인된 이전 시안과 같습니다.

순환 팔레트는 214–217, 218–221, 231–235, 238–241이며 새 글자에는 사용하지 않습니다. 두 순환 길이 4·5의 공통 주기인 20단계를 재현해 버튼 색이 변하지 않는지 검사했습니다. 원래 배경의 애니메이션은 유지합니다.

## 배포 데이터

`translations/interface/main_menu/`에는 원본 ICN에 대한 BSDIFF40 델타 3개와 `identities.json`을 저장합니다. 원작 이미지나 완성 ICN·AGG·캡처는 포함하지 않습니다.

| 아카이브 / 리소스 | 크기 | 승인 SHA-256 |
|---|---:|---|
| `HEROES2.AGG / BTNSHNGL.ICN` | 96,428 | `4B4AC170B417149BB48B15FEFB6894051C6CD3E0AC1A6ADAF60C0235A126CD28` |
| `HEROES2.AGG / HEROES.ICN` | 310,580 | `9CE77CBEC2D830F795513B68805B9D21FB1391E2D5058F70DA2AD13E4159F0C4` |
| `HEROES2X.AGG / HEROES.ICN` | 310,580 | `E9301B5BD4EC879B09C26163255787D40D2596E55244FDE72040B27ED1998310` |

빌더는 원본과 델타의 identity를 확인한 뒤 승인 결과를 복원합니다. 기존 한국어 패치의 다른 리소스를 유지하며 메뉴만 추가하고, 결과를 두 AGG의 폰트 없는 기반 델타에 포함합니다. 설치기의 동적 글꼴 처리는 메뉴를 다시 그리지 않습니다.

## 검증 기준

- source·delta·target identity, BSDIFF40 형식과 ICN 왕복 보존
- 20개 버튼의 위치·크기·투명도 및 편집 영역 밖 픽셀 보존
- 메인 메뉴 버튼의 순환 팔레트 0개
- 기본판·확장판 배경의 메뉴 영역과 상태 0 donor 일치
- 기본·사용자 글꼴 설치 모두 승인 메뉴 3개 payload 일치
- beta.12의 일반 버튼·글리프·번역·EXE·은행·캠페인 보존

설치·업그레이드 검사는 [재포장 절차](../BUILD_KO.md)를 따릅니다.
